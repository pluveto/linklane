# Linklane v0.2.0

- 在原有身份卡片中加入浏览器标识，支持标准安装位置的 Chrome、Edge、Brave 与 Firefox。
- 新增高级规则编辑器：域名／子域、协议、端口范围、路径、查询参数、完整 URL、通配符、正则及组合／排除条件。
- 规则从上到下执行，首条命中生效；支持打开指定身份或询问。草稿测试及 `--explain` 展示匹配原因。
- 保留精确网站记忆、身份重命名和最近使用排序；旧配置在备份后迁移，保存失败保留原文件。
- 多窗口保存采用原子写入与规则版本检查，自动打开产生的最近记录可独立合并。

详细语法见包内 `docs/RULES.md` 或应用内“高级规则 → 示例与身份标识”。更新前可复制安装目录和设置目录；恢复旧版时同时恢复旧程序与 `settings.v1.backup.json`。
