# 轻舟 Linklane v0.4.0

### 更新内容
- 支持 Chrome、Edge、Brave、Firefox 身份及按网址匹配。
- 可识别跳转目的地，打开时保留原链接。
- 规则文件顶部写明各条件写法；原 JSON 留作备份，旧设置需手动转写。
- 提供 CLI 命令行支持：
  - `rules check FILE`：校验
  - `rules replace FILE`：校验并应用
  - `rules identities`：列身份
  - `rules explain URL`：看匹配

### 怎样安装
解压 ZIP 压缩包（包含相邻的 `linklane.exe` 和 `linklane-cli.exe`），运行主程序，点击“开始使用”。

### 给 AI 的用法
- 底部网站设置显示 TOML 文件路径，复制即可给 AI 用于配置规则。
- 编辑后点击“从文件重新加载”；若失败仍使用上次生效设置并显示错误。
