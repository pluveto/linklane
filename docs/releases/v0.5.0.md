### 新特性

支持记住特定路径的打开方式，范围由网址本身决定。

**使用示例：**
打开 `https://example.com/team/project` 时，「下次记住」处于勾选状态，可选择以下范围后再点击浏览器身份：
* `https://example.com` 下的所有链接（默认）
* `/team` 及下级
* `/team/project` 及下级

取消勾选则只打开这一次。

### 升级方式

1. 关闭旧版轻舟窗口。
2. 解压 Windows x64 ZIP 压缩包。
3. 在解压目录打开 PowerShell，运行命令完成替换安装：

```powershell
.\linklane.exe --install
```

该操作保留已有设置和身份。
